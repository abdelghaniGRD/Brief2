# 🌿 Arganik — Site vitrine d'une coopérative féminine

## 1. Présentation du projet

Arganik est un site web vitrine dédié à une coopérative féminine de la région du Souss-Massa, spécialisée dans les produits naturels et artisanaux.

Le projet a pour objectif de valoriser le savoir-faire local, présenter les produits de la coopérative et mettre en avant son engagement en faveur d'une production naturelle et solidaire.

Le site comprend cinq pages conçues pour offrir une expérience utilisateur claire, agréable et adaptée aux différents écrans.

## 6. 🔀 Organisation Git Flow

Le travail est organisé avec Git et GitHub afin de faciliter le développement collaboratif.

- **`master`** : branche contenant la version stable du projet.
- **`dev`** : branche dédiée au développement et à l'intégration.
- **`feature/*`** : branches dédiées aux fonctionnalités développées par les membres de l'équipe.

### Workflow de collaboration

1. Chaque membre travaille sur sa branche `feature/*`.
2. Les modifications sont envoyées sur GitHub avec `git push`.
3. Une Pull Request est créée vers la branche cible définie par l'équipe.
4. Un autre membre relit les modifications et propose des corrections si nécessaire.
5. Après validation, la Pull Request est fusionnée dans la branche cible.
6. La version finale est vérifiée avant sa mise à jour sur la branche stable.

L'historique GitHub permet de suivre les contributions, les Pull Requests, les revues de code et les merges.
